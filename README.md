# sk-blog

A minimal, modern-design inspired personal blog built with [SvelteKit](https://kit.svelte.dev/), Markdown, and Tailwind CSS.

---

## Overview

sk-blog is a modern, developer-friendly blogging platform that uses Markdown files for its content, provides a clean and simple structure, and makes it easy to deploy anywhere. You write your posts in Markdown with frontmatter, and the site auto-generates blog home, category/tag views, and detail pages—no database or heavyweight CMS required.

**Main features:**
- Write posts in plain Markdown (`content/posts/*.md`)
- Frontmatter support for title, date, excerpt, tags, categories, images, etc.
- Blog home, category pages (`/categories/`), tag pages (`/tags/<tag>/`) — all auto-generated
- Pretty, mobile-friendly UI inspired by Swiss design, styled with Tailwind CSS
- Markdown converted to HTML automatically; fast and SEO-optimized
- Deploys to Vercel, Netlify, Cloudflare Pages, or any static host
- Clean, simple, and extendable codebase

## Folder Structure

```
content/
└── posts/
    ├── building-a-blog.md
    ├── my-experience-with-sveltekit.md
    └── another-post.md

src/
└── routes/
    ├── +page.svelte            # homepage (recent/featured posts)
    ├── categories/             # categories list page
    ├── category/[slug]/        # posts for a specific category
    ├── post/[slug]/            # individual post view
    └── ...                     # error and layout pages
```

---

## How It Works

1. **Posts**: Drop your Markdown files in `content/posts/` with a frontmatter block (title, date, etc.).
2. **Data Handling**: Utilities in `src/lib/utils/posts.ts` parse Markdown, extract metadata, compute reading time, collect categories/tags, etc.
3. **Pages**: SvelteKit route files render lists, categories, tag views, and each blog post.
4. **Components**: Navbar, footer, post cards, and badges are all simple and extensible Svelte components.

**Example frontmatter for a Markdown post:**
```markdown
---
title: "Why SvelteKit is Awesome"
date: "2026-02-03"
excerpt: "SvelteKit offers a delightful developer experience with great performance..."
tags: ["sveltekit", "javascript"]
categories: ["Web Dev"]
featuredImage: "/images/sveltekit.png"
author: "Your Name"
---

Write your post below in Markdown...
```

## Tech Stack

- **SvelteKit** — app framework (routes and rendering)
- **Tailwind CSS** — component-first styling
- **gray-matter** — parses frontmatter from Markdown files
- **marked** — converts Markdown to HTML

## Development

Clone, install dependencies, and start the dev server:

```bash
git clone https://github.com/malishehahbi/sk-blog.git
cd sk-blog
npm install
npm run dev           # or 'npm run dev -- --open' to launch browser automatically
```

## Building & Deployment

To build for production:

```bash
npm run build
npm run preview       # to preview the production build locally
```

sk-blog works anywhere you can run Node.js or serve static files, including:

- Vercel / Netlify / Cloudflare Pages
- Traditional VPS hosting
- Any CDN/static host (after a static export)

**Change the base path in `svelte.config.js` if deploying to a subfolder (e.g., GitHub Pages):**
```js
paths: { base: '/sk-blog' }
```
